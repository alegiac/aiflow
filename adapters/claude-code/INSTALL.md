# Claude Code

Esegui `aiflow init` e `aiflow integrate claude` dalla root del progetto. Le istruzioni sono inserite in `CLAUDE.md` in una sezione delimitata; le skill locali sono in `.claude/skills/aiflow-*/SKILL.md`, le descrizioni degli agenti in `.claude/agents/`. Riavvia la sessione Claude per ricaricare. Verifica il riconoscimento delle skill e il comando `aiflow status`. I subagenti non vengono avviati automaticamente, né sono concesse autorizzazioni di esecuzione privilegiate.
