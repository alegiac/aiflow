# Codex CLI

Esegui `aiflow init` e `aiflow integrate codex` dalla root del progetto. Le istruzioni sono inserite in `AGENTS.md` in una sezione delimitata, e le skill locali sono in `.agents/skills/aiflow-*/SKILL.md`. Riavvia la sessione Codex per ricaricare le istruzioni. Verifica che Codex riconosca le skill nella versione installata e che `aiflow status` sia eseguibile. Nessun permesso viene elevato automaticamente.
