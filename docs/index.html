AIFlow adds a persistent, reviewable workflow to AI-assisted software development. Plan epics, track tasks, record decisions, and recover context while working with Codex CLI or Claude Code.

Get started⭐ Star on GitHubLatest release

A workflow, not another agent

Keep the developer in charge, with durable project state and human-readable artifacts.

🧭 Epics & tasks

Break work into scoped, verifiable units with explicit lifecycle transitions.

📝 Decisions & approvals

Record important choices and human approval evidence instead of losing them in chat history.

🔄 Recovery & checkpoints

Resume work with saved context, checkpoints, sessions and reports.

🤝 Codex & Claude

Integrate with Codex CLI and Claude Code in each initialized project.

🔒 Local-first state

SQLite for operational state; Markdown for reviewable, versionable project artifacts.

🧩 Community profiles

Contribute language and framework guidance as Markdown profiles, without changing the engine.

Start building

Requires Python 3 and macOS or Linux. Inspect scripts before running them, as with any downloaded installer.

curl -fsSL https://raw.githubusercontent.com/alegiac/aiflow/main/install.sh -o aiflow-install.sh sh aiflow-install.sh mkdir my-project && cd my-project aiflow init --profile php-laravel aiflow integrate both aiflow doctor

Use aiflow upgrade for stable releases, aiflow upgrade --beta for prereleases, or aiflow upgrade --dev for the latest main branch. Check the README for full documentation.
