# AIFlow 1.4.0 — implementation preview

This branch is **experimental**, not ready for release.

## Daily workflow
```sh
aiflow day start
aiflow day end --summary "Implemented API; next: integration tests"
aiflow day start --json
```
Start resumes an existing session; end closes active session and tracking. Neither automatically accepts tasks. Date is a reporting label.

## Adopt
```sh
cd /path/to/existing/project
aiflow adopt
aiflow adopt --conversation /path/to/export.md
aiflow adopt --apply
```
Preview is read-only. Apply invokes existing init and writes `.ai/adoption-review.json`. Conversation exports are only sampled for review, not automatically converted into decisions or tasks. No private provider history is accessed.

## Jira bridge (initial REST adapter)
```sh
export AIFLOW_JIRA_URL=https://example.atlassian.net
export AIFLOW_JIRA_EMAIL=developer@example.com
export AIFLOW_JIRA_TOKEN=... # use shell secrets manager
aiflow tracker status
aiflow tracker map EPIC-001/TASK-001 PROJ-123
aiflow tracker pull PROJ-123
aiflow tracker worklog 1           # preview
aiflow tracker worklog 1 --apply   # POST worklog
```
Worklog sync currently records a successful Jira response locally. **Do not retry automatically** if the request timed out after Jira accepted it: inspect Jira for duplicate worklogs first. Bidirectional issue sync, MCP adapter, conflict resolution, and robust cross-system idempotency are still pending.
