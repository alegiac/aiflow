# AIFlow 1.4.0 — Daily Workflow & Existing Project Adoption

This release contains **no Jira, MCP, or external tracker integration**. Existing local time tracking remains available.

## Daily workflow
```sh
aiflow day start
aiflow day start --json
aiflow day end --summary "API completed" --next "Integration tests"
```
Daily start resumes an open session and summarizes pending tasks. Daily end closes active local tracking, ends the session, and saves a local checkpoint. Repeated end calls are harmless.

## Adopt an existing project
```sh
cd /path/to/existing/project
aiflow adopt
aiflow adopt --conversation /path/to/export.md
aiflow adopt --conversation /path/to/export.md --apply
```
Preview does not modify project files. Apply initializes AIFlow and generates `.ai/adoption-review.json` and `.ai/adoption-review.md`. Git history, manifest dependencies, and selected transcript excerpts provide evidence for human review. No unverified statement is treated as an approved decision. Conversation access requires an explicit exported file; no private provider history is accessible automatically.

## Release checklist
- Run full test suite and packaging workflow.
- Validate adopt with existing nonempty projects and different agent transcript formats.
- Verify documentation, version metadata and upgrade compatibility.
- Merge and tag v1.4.0 only after checks pass.

Jira/MCP and external issue/time sync are explicitly deferred to a future release.
