# start-epic

## Scopo
Apri una Epic approvata.

## Procedura
Verifica approvazione e ID univoco; crea directory Epic e template; registra obiettivi, scope, criteri e dipendenze; collega ADR; proponi scomposizione Task senza avviarli automaticamente.

## Vincoli
Seguire `core/GOVERNANCE.md`. Non inventare conferme. Per le attività documentali, salvare in modo incrementale; in caso di conflitto chiedere chiarimenti. La skill non concede permessi ulteriori rispetto all'ambiente host.

## Output
Epic attiva e collegamenti ai documenti.
