# init-project

## Scopo
Inizializza il contesto del repository senza imporre stack o generare documenti inutili.

## Procedura
Raccogli nome, obiettivo e vincoli mancanti con domande mirate; ispeziona il repository solo dopo conferma; identifica stack e convenzioni effettive; proponi file da creare/aggiornare; attendi approvazione; preserva i file esistenti.

## Vincoli
Seguire `core/GOVERNANCE.md`. Non inventare conferme. Per le attività documentali, salvare in modo incrementale; in caso di conflitto chiedere chiarimenti. La skill non concede permessi ulteriori rispetto all'ambiente host.

## Output
Inventario dei file creati, evidenze, ipotesi da verificare e prossimo passo.
