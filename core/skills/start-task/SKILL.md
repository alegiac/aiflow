# start-task

## Scopo
Avvia un Task approvato e il suo tracking.

## Procedura
Verifica Epic, Task e scope; recupera solo contesto rilevante; annota ora inizio e stato nel tracking; prepara piano breve, file interessati, rischi e test; per cambi significativi chiedi approvazione prima di modificare codice.

## Vincoli
Seguire `core/GOVERNANCE.md`. Non inventare conferme. Per le attività documentali, salvare in modo incrementale; in caso di conflitto chiedere chiarimenti. La skill non concede permessi ulteriori rispetto all'ambiente host.

## Output
Task in progress, piano e tracking aggiornati.
